================================================================================
LANGKAH TRANSFER KE LAPTOP BARU:
================================================================================
1. Install dan buka aplikasi Antigravity minimal 1x di laptop baru agar folder
   ~/.gemini/antigravity terbentuk, lalu TUTUP aplikasi Antigravity sepenuhnya.

2. Clone salah satu repositori GitHub Anda di laptop:
   - Repo skripsi lengkap (private):
     git clone https://github.com/Treamyracle/skripsi.git
     cd skripsi
   - Atau repo bab4 & dataset 18-kelas (public):
     git clone https://github.com/Treamyracle/bab4.git
     cd bab4

3. Jalankan skrip pemulihan dari root folder repositori:
   python antigravity_device_migration/restore_session.py

4. Buka kembali Antigravity, lalu pilih Open Folder ke folder repo hasil clone.
   Percakapan 'SKRIPSI' (ID: 81089962-53ae-4754-ac53-0a755e441870) akan langsung
   muncul di sidebar obrolan dan siap dilanjutkan!

5. (Opsional) Jika nanti ingin menjalankan skrip OpenRouter di laptop,
   set environment variable OPENROUTER_API_KEY secara lokal (kunci asli sengaja
   tidak disimpan di GitHub demi keamanan):
   [Environment]::SetEnvironmentVariable("OPENROUTER_API_KEY", "sk-or-v1-...", "User")
